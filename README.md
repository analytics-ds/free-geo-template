# free-geo-template

Maquettes datashake de pages GEO friendly pour Free, sur le modèle de `kiabi-geo-template`. DA free.fr conservée, contenus retravaillés pour ChatGPT, Gemini et les AI Overviews. Les pastilles rouges expliquent chaque ajout et son pourquoi. Pages non indexables (`noindex, nofollow`), démonstration non affiliée à Free.

| Page | Rôle |
|---|---|
| `freebox.html` | transactionnel box internet et fibre |
| `forfaits.html` | transactionnel forfait mobile |
| `guide.html` | modèle d'article informationnel |
